# Guide des Agents et Compétences du Projet

Ce référentiel contient la configuration et les compétences dédiées au développement de la solution Essentiel Commune.

## Compétences (.agents/skills/)

1. **communes-data-pipeline** : Pipeline de données (APIs territoriales, découpage administratif, Insee).
2. **france-map-explorer** : Exploration et navigation cartographique interactive.
3. **commune-card** : Composant d'affichage synthétique des données communales.
4. **commune-newsletter-page** : Modèles de pages et gestion des bulletins d'information municipaux.
5. **site-seo-performance** : Optimisations SEO, performance web et Core Web Vitals.
6. **conformite-juridique** : Conformité légale, RGPD, mentions légales et RGAA.

## Modules optionnels (optionnel/)

- **newsletter-subscription-rgpd** : Système d'abonnement à la newsletter conforme au RGPD.
